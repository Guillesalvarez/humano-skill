# humano

Skill para Claude Code que escribe o reescribe texto en español para que no suene a IA. Se basa en el catálogo de Wikipedia [Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing).

## Instalación

Copia la carpeta `humano` a `~/.claude/skills/`:

```bash
cp -R humano ~/.claude/skills/
```

## Uso

- `/humano <tema>` redacta un texto desde cero.
- `/humano` seguido de un texto pegado lo reescribe sin cambiar los hechos.
